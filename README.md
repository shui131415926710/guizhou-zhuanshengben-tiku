# 贵州专升本真题与模拟卷（临时站）

贵州专升本「高等数学」「英语」历年真题 + 模拟卷的静态浏览站点，数据采集自库课网校（kuke99.com）贵州专升本题库的「历年真题」与「模拟考场」两个模块。

**仅用于个人复习存档，请勿公开传播或用于商业用途。**

## 内容规模

| 科目 | 历年真题 | 模拟卷 | 题量 |
| --- | --- | --- | --- |
| 高等数学 | 9 套（2018–2026，26 题/套） | 17 套（模拟试卷 01–17，26 题/套） | 234 + 442 = 676 |
| 英语 | 5 套（2020–2024，76 题/套） | 65 套（模拟试卷 01–65，76–77 题/套） | 380 + 约 4960 = 5340 |
| **合计** | **14 套** | **82 套** | **6016 题** |

> 2025、2026 两套高数真题由本地 PDF 转录录入，题干/选项公式以 KaTeX 文本存储；原卷未附标准答案与解析，这两套的答案字段留空，可在页面上点 AI 小球答疑获取。

每套试卷包含：题干、选项、参考答案、文字解析（部分）、试题统计（正确率 / 易错项 / 作答次数）。

## 目录结构

```
.
├── index.html        # 题库浏览页（无依赖，纯静态）
├── study.html        # 刷题工作台：数学草稿纸 / 英语文章精读标注
├── data-meta.js      # 试卷清单与统计（约 21 KB）
├── papers/           # 96 个试卷数据文件，一套一个（平均 89 KB，最大 134 KB）
│   ├── math-2024.js      # 真题：<科目>-<年份>
│   ├── math-sim-01.js    # 模拟卷：<科目>-sim-<编号>
│   └── ...
├── data.json         # 全量数据（8.5 MB，标准 JSON，便于二次处理；站点不加载）
├── build_data.py     # 把原始采集 JSON 规范化成上述数据文件
└── README.md
```

页面只为**当前点开的那一套**注入 `papers/<id>.js`，首屏仅加载 `data-meta.js`（21 KB）。点开一套试卷约 0.1–0.2 秒（本地），线上约 1–3 秒。

## 刷题工作台（study.html）

`study.html` 是配合做题的独立页面，共用同一套 `data-meta.js` / `papers/` 数据。

**数学 · 草稿纸**

- 点每题右上「草稿纸」进入全屏手写板（支持鼠标、触控笔、压感笔；有笔/橡皮/移动画布、6 种颜色、粗细、撤销、清空、导出 PNG）
- 右侧「题目浮窗」始终置顶显示当前题（题干 + 选项），可拖到屏幕任意位置、可调透明度、可上一题/下一题；滚轮缩放画布（`100%` 复位）
- 浮窗内选项可直接点选作答，与页面题卡双向同步
- 每道题的笔迹独立保存到本机（`localStorage`），下次打开同一题自动恢复

**英语 · 文章精读**

- 点材料上的「精读 / 标注」把阅读材料抽到独立全屏面板，正文可放大字号（A− / A+）
- 面板上直接手写圈画重点（笔色可选、可撤销、可清空、可导出图片），标注按「文章」维度保存
- 右侧同步列出该材料对应的全部小题与选项，每题可单独展开参考答案与解析

**直达链接**：`study.html?paper=eng-2024&open=reader&q=31`（打开 2024 英语第 31 题材料精读）、`study.html?paper=math-2024&open=board&q=10`（打开 2024 高数第 10 题草稿纸）。

## 本地查看

直接双击 `index.html` 即可（数据以 `<script>` 形式按套注入，不需要本地服务器）。

> 题干、选项、答案中的公式/表格均为图片，直接引用原站 CDN（`oss.kuke99.com`）。该 CDN 有 Referer 防盗链，页面已设置 `<meta name="referrer" content="no-referrer">`；因此**需要联网**才能显示公式，且不要移除这行 meta。

## 页面功能

- 科目切换：高等数学 / 英语
- 分类切换：历年真题（按年份倒序）/ 模拟卷（按编号正序）
- 逐题查看答案：每题「查看答案」展开参考答案、解析与试题统计
- 选项点选：选择题点击选项即可作答，选择按题保存在本机；展开答案后正确项转绿、错选转红
- 一键展开 / 收起全部答案
- 关键词搜索：过滤题干、选项、答案中包含关键词的题目（仅在已加载的那一套内搜索）
- 右上角「刷题工作台」进入 `study.html`（数学草稿纸 / 英语文章精读标注）


## 重新构建数据

原始采集文件位于 `D:\yx\llq\`，文件名约定：

- `kuke_{math|eng}_{年份}.json` —— 历年真题
- `kuke_{math|eng}_sim_{编号}.json` —— 模拟卷
- `_map_{math|eng}_sim.json` —— 模拟卷编号 ↔ testpaperId 映射（采集用）

原始结构：`{title, questions:[{qno, score, stem, opts[], ansText, ansHtml, stat}]}`

```bash
python build_data.py
```

脚本会输出 `data.json`、`data-meta.js`、`data-math.js`、`data-eng.js`，并打印各卷题量与分值合计。

## 数据说明与已知差异

- **分值**：以原题库题干标注为准。个别题目原站未标注分值，页面显示「分值未标注」，未做推断补齐；因此「题干标注合计」与官方总分 150 有出入（英语 138、部分高数卷 148–149）。试卷头部展示的官方总分为 150。
- **选择题答案**：取自解析页中正确选项的绿色高亮标记，并与 `ansText` 字母交叉校验。
- **主观题答案**：填空/计算/证明/翻译/写作题的答案多为图片，存于 `answerHtml` 字段。
- **2024 高数**：首次采集时标题与分值字段未取到，构建脚本按题干正则 `(N分)` 与年份补全。
- **模拟卷题量**：英语模拟卷 01、02 为 77 题，其余为 76 题；高数模拟卷统一 26 题。

## 数据校正记录（2026-11-18 全量重采）

- 早期采集按「题型分组容器」定位题目，导致**组尾题**（如数学第 10/20/24 题）向上浮到整组容器、抓走整组内容，表现为一题多选项、后续题无选项（全局 818 处异常、约 560 题受影响）。现已改为按题干 `N、` 逐题切分，94 套全部重采。
- 英语完形填空 / 阅读理解的材料是**独立文本块**（不在题干里），早期被整块跳过，导致 31–40 题只剩 `( )` 和选项。现已识别并随题继承，材料在题卡与精读面板中均可完整阅读。
- 全量验收：题号连续、题干编号与题号一致、每题恰 1 个正确选项且答案文本落在选项集合内、主观题均有解析、答案图跨题无重复 —— 全部通过。
- 唯一已知源站问题：`kuke_eng_sim_33` 第 5 题与第 28 题题干 + 选项完全相同（作答 640 次 / 563 次、正确率 66.6% / 70% 不同，属原题库重复录入），保留原样未改动。
- 部分模拟题的选项正文直接印在题干图片里，选项字段只有字母，页面按「见题干图」提示，未臆造内容。
